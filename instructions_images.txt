The Industries ("Cargo & Industries We Support") section on the home page is
built as six full-bleed, image-forward showcase sections. Placeholders
currently ship from:  scripts/generate_sector_placeholders.py
  -> regenerates:  python scripts/generate_sector_placeholders.py

This document specifies the FINAL imagery to replace those placeholders.
Drop-in replacement requires zero code changes: keep the exact filenames and
paths below (the components read them from lib/data/industries.ts).

--------------------------------------------------------------------------------
1. GLOBAL PHOTOGRAPHY STYLE GUIDE
--------------------------------------------------------------------------------

1.1 COMPOSITION
  - Cinematic wide-angle establishing shots; the story lives in the vehicle,
    the load, and the environment together — never a generic truck cut-out.
  - Shallow depth of field where possible (subject tack-sharp, background
    softly compressed). Telephoto compression (85mm–200mm full-frame
    equivalent) is preferred for side-profile vehicle shots; 24mm–35mm for
    scene-setting wides.
  - Authentic African trade corridors: N4/N1 Southern African highways, SADC
    border posts, open-pit mines, grain belts, industrial precincts, remote
    construction sites and inland container terminals.
  - Dusk / dawn "golden hour" industrial lighting as the default mood.
    Night shots are acceptable only when lit by site floodlights or vehicle
    work lights for the six images as a set.
  - Leave negative space on ONE side of the frame (left or right) — the UI
    overlays a dark gradient scrim + text on that side. Text-safe side must
    stay free of critical detail. Each sector below names its text-safe side.
  - Focal point of every image should sit slightly off-center toward the
    RIGHT third of the frame (matching the CSS focal hints in
    lib/data/industries.ts), unless noted otherwise.

1.2 COLOR GRADING
  - Warm cinematic grade. High contrast, deep shadows that stay readable.
  - Brand-adjacent palette anchors: earthy greens (forest #12382f family),
    dark charcoal, warm ochres/gold (#d4a44c), terracotta accents (#b9623e),
    warm cream highlights (#f8f4eb).
  - Sky tones: golden-spectrum dusk, hazy green-gold morning, warm industrial
    haze. Avoid blue-dominant or heavily saturated HDR looks.

  - Realistic, filmic grain is welcome — NON-generic stock look. No visible
    watermarks, no fake lens flares, no cartoonish over-processing.
  - Trucks/vehicles should be neutral (white, charcoal, dark green or earth
    tones) so any future brand livery can be recoloured in post.

1.3 TECHNICAL / DELIVERY SPEC
  - Aspect ratio: 16:9  (portrait crops NOT required; CSS object-fit: cover
    + object-position handle responsive cropping)
  - Resolution: 1920 x 1080 px (min. 1600 x 900; never upscale)
  - DPI: 72–96 (screen use)
  - Format: WebP, visually lossless quality (~q80), under 300 KB per file.
    (Reduce width to 1600 if a scene cannot hit 300 KB.)
  - Color profile: sRGB
  - File naming (exact, lowercase, hyphenated — mirrors industry ids):
      public/images/sectors/mining-minerals.webp
      public/images/sectors/agriculture.webp
      public/images/sectors/construction.webp
      public/images/sectors/manufacturing.webp
      public/images/sectors/trade-distribution.webp
      public/images/sectors/project-cargo.webp
  - Compression reference:
      cwebp -q 80 -resize 1920 0 input.jpg -o output.webp
      (or: python -c "from PIL import Image; Image.open('in.jpg').save(
           'out.webp', quality=80, method=6)")
  - Licensing: commercial, perpetual, worldwide web use; model/property
    releases where identifiable people/plates appear. Blur or avoid readable
    third-party branding and competitor liveries.

  - SET CONSISTENCY (critical): the six images render as one scrolling
    sequence. Keep a shared grade, shared time-of-day family and shared
    horizon height so the page reads as one story, not six postcards.

3. FLUX / OTHER GENERATORS — GLOBAL NEGATIVE PROMPT
--------------------------------------------------------------------------------
Append or enable as negatives everywhere:
  generic stock photo look, oversized watermark, spoke wheels mismatch,
  deformed vehicle wheels, cartoon, 3D render, oversaturated HDR, blue
  cold grade, front-on dealer-shot composition, busy cluttered left side,
  readable third-party logos, license plates, smoke without source

FLUX guidance preference: run as "cinematic photography" (not illustration),
steps 28+, guidance ~3.5, then export sRGB WebP per §1.3.

--------------------------------------------------------------------------------
4. QA CHECKLIST BEFORE SHIPPING TO public/images/sectors/
--------------------------------------------------------------------------------
[ ] Exact filename from §1.3, lowercase, .webp, sRGB
[ ] 16:9, >=1600x900, file size <300 KB
[ ] Text-safe side genuinely empty of critical subject detail
[ ] Six images grade as one consistent, warm, high-contrast set
[ ] No readable third-party branding; releases on file where required
[ ] Visual QA in place: view / (desktop + <1024px mobile) — text must pass
    contrast over the scrim on every card, focal points must not clip
